# 网络与代理

程序需要访问 Telegram 和 X。请先确认设备本身能够正常访问这两个服务。

需要代理时，在自己的 `.env` 中设置：

```dotenv
ARCHIVER_PROXY_URL=http://your-proxy-host:7890
```

这只是占位示例，请替换成你自己容器能访问的 HTTP CONNECT 代理地址及端口。当前个人模式仅接受不含用户名、密码、路径或查询参数的 `http://主机:端口`。不支持代理订阅链接，配置失败也不会静默回退直连。

容器里的 `127.0.0.1` 指向容器自己，通常不是宿主机。Docker Desktop 与 Linux/NAS 的宿主机访问方式不同；请按 Docker 或厂商文档配置，不要为本项目修改整个 NAS 的系统代理。

公开版不自带代理节点、订阅、Mihomo 二进制或代理管理服务。不要把私人订阅、令牌或配置文件上传到仓库和 Issues。
